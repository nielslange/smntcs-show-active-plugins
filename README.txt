Adds an Active Plugins link to the Plugins menu, so you can see all active plugins in one click.

== Description ==

The Plugins menu in WordPress links to Installed Plugins and Add New Plugin. To see only the active plugins you have to open Installed Plugins and then pick the Active view.

SMNTCS Show Active Plugins adds an Active Plugins link to the Plugins menu that takes you straight there.

== Installation ==

1. Upload `smntcs-show-active-plugins` to the `/wp-content/plugins/` directory.
2. Activate the plugin through the `Plugins` menu in WordPress.
3. Go to the `Plugins` menu and click on `Show Active Plugins`.
